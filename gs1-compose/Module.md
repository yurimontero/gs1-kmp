# Module gs1-compose

Compose Multiplatform composables, painters and bitmaps for the symbols made by `gs1-core`.

# Package io.github.yurimontero.gs1.compose

Composables ([Gs1DataMatrixBarcode], [Gs1Code128Barcode], [Gs1QrCodeBarcode]), painters for `Image`, and
`toImageBitmap` for sharing or printing. Modules are always drawn with whole pixels so the symbols stay sharp.
